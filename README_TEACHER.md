## เริ่มใช้ครั้งแรก (ผู้ดูแล)
1. **ตั้งค่าระบบ** → เพิ่มภาคเรียน แล้วตั้งเป็นภาคเรียนปัจจุบัน
2. **ผู้ใช้และสิทธิ์** → เพิ่มอีเมลอาจารย์ แล้วติ๊กระบบที่ให้ใช้: `att` เช็คชื่อ · `asg` ส่งงาน · `exam` สอบ
3. **ตั้งค่าระบบ** → ปรับค่าเริ่มต้นเช็คชื่อ (รัศมี, เวลาปกติ/สาย), ขนาด/ชนิดไฟล์งาน, การล็อก PIN

## เปิดวิชา
1. **รายวิชา** → สร้างวิชา (รหัส + ชื่อ + กลุ่ม) ในภาคเรียนปัจจุบัน
2. **นักศึกษา** → เพิ่มทีละคน หรือนำเข้า CSV / วางจาก Excel (บันทึก Excel เป็น *CSV UTF-8*)
3. **คะแนน** → ตั้ง **สัดส่วน %** ของแต่ละประเภท (รวมไม่เกิน 100) · มี 5 ประเภท เลือกจาก dropdown และดูแถบสีด้านบน:
   - **เข้าเรียน** (สีน้ำเงิน) — ระบบคิดให้จากเช็คชื่อ = ครั้งที่เข้า ÷ คาบที่ปิดแล้ว × 100 (ปกติ 1 · สาย 0.5 · ลา/ขาด 0)
   - **คะแนนเก็บ** (สีเขียว) — จากระบบส่งงาน ตั้งคะแนนเต็ม + สัดส่วนตอนสั่งงาน ตรวจงานกรอกคะแนนดิบ ระบบแปลงเป็น % ให้
   - **คะแนนทดสอบ** (สีส้ม) — จากระบบสอบ ตั้งแค่สัดส่วนของแต่ละรอบ
   - **สอบกลางภาค / สอบปลายภาค** (สีม่วง / ชมพู) — กด “ตั้งสัดส่วน…” แล้ว “วางจาก Excel” (รหัสนักศึกษา + คะแนนเป็น %)
   - ค่าเริ่มต้นของทุกประเภท: **ไม่แสดงคะแนนให้นักศึกษาเห็น** (เปิดได้ทีละรายการ)

## ใช้งานประจำ
| งาน | ทำอย่างไร |
|---|---|
| เช็คชื่อ | หน้าวิชา → เช็คชื่อ → ตั้ง **เวลาเริ่ม** (แสดงเวลาตอนนี้ให้เอง) · **ปกติ ภายใน … นาที** · **สาย ถึง … นาที** · คะแนน ปกติ/สาย/ขาด (ไม่ปรับ = ค่าเริ่มต้นของระบบ 1 / 0.5 / 0) → ดู “สรุปการคำนวณ” → "ใช้ตำแหน่งปัจจุบัน" → เปิดคาบ → ฉาย QR/ลิงก์ · เลยเวลาสาย = ขาด และ**ปิดคาบอัตโนมัติ** · พัก/ต่อคาบได้ · แก้สถานะย้อนหลังได้ |
| ส่งงาน | หน้าวิชา → งาน → สั่งงาน (ตั้งคะแนนเต็ม · สัดส่วน % · ติ๊ก “ต้องแนบไฟล์” — ค่าเริ่มต้นต้องแนบ) → กด "แจ้งนักศึกษา" คัดลอกข้อความ+ลิงก์ · ตรวจและกรอกคะแนนในหน้างาน (ระบบแปลงเป็น % ให้) |
| สอบ | หน้าวิชา → สอบ → สร้างชุดข้อสอบ (ติ๊กข้อถูก) → สร้างรอบ → กด "แจ้งนักศึกษา" · ดูผลสด/สถิติได้ |
| คะแนน | คะแนนจากเช็คชื่อ/งาน/สอบเข้าตารางคะแนนอัตโนมัติ · ส่งออก CSV |

## สรุปคะแนนรายวิชา และเกรด
หน้าวิชา → **สรุปคะแนน** (หรือปุ่ม “สรุปคะแนน / เกรด” ที่หน้าคะแนน) — ทุกคน × ทุกประเภทในหน้าเดียว + สถิติ (เฉลี่ย/สูงสุด/ต่ำสุดต่อประเภทและรวม) + จำนวนคนแต่ละเกรด · ค้นหา/เรียงตามรหัส ชื่อ คะแนนรวม
- **แก้ได้ทุกช่อง:** คลิกตัวเลข → ใส่คะแนนใหม่ (เหตุผลไม่บังคับ) · ช่องที่ระบบคิดให้ (เช็คชื่อ/งาน/สอบ) ที่แก้ทับจะมี **✎** สีเหลือง และ**ระบบไม่ทับให้อีก** แม้คาบ/งาน/สอบถูกคิดใหม่ (ระบบจำ “ค่าระบบล่าสุด” ไว้เทียบ) · กด **คืนค่าระบบ** หรือเว้นว่างแล้วบันทึก เพื่อเลิกแก้
- **คะแนนปรับ +/−:** คลิกช่อง “ปรับ” → ใส่เช่น −5 (ไม่ช่วยงานกลุ่ม) หรือ +3 (โบนัส) เป็น % ของคะแนนรวมวิชา · เหตุผลไม่บังคับ · ใส่ 0/ว่าง = ลบ · เกรดคิดจากคะแนนรวมหลังปรับ
- **เกณฑ์เกรด:** ปุ่ม “เกณฑ์เกรด” (ค่าเริ่มต้น A≥80 · B+≥75 · B≥70 · C+≥65 · C≥60 · D+≥55 · D≥50 · ต่ำกว่า = F) ตั้งแยกรายวิชาได้ · คนที่ยังไม่มีคะแนนเลยไม่ถูกตัดเกรด
- ส่งออก CSV มีคอลัมน์ รวมก่อนปรับ · คะแนนปรับ · รวมหลังปรับ · เกรด · นักศึกษาไม่เห็นคะแนนปรับ/เกรด (ยังไม่มีหน้าดูคะแนนฝั่งนักศึกษา)
- ถ้าสัดส่วนรวมยังไม่ครบ 100% หน้านี้เตือน เพราะคะแนนรวมและเกรดจะต่ำกว่าจริง

## รายการจำนวนมาก: ค้นหา · เรียง · เลือกหลายรายการ
หน้า **รายชื่อนักศึกษา · งาน (ส่งงาน) · ประวัติคาบเช็คชื่อ · รอบสอบ · แบบทดสอบ** มีแถบเครื่องมือเหนือรายการ: ช่องค้นหา · เรียงตาม … (สลับทิศทางได้) · ติ๊ก **เลือกทั้งหมดที่แสดง** (เลือกเฉพาะที่ค้นหาเจอ) · ปุ่มคำสั่งกลุ่ม เช่น **ลบที่เลือก** (ขึ้นสรุปสิ่งที่จะหายก่อนยืนยันทุกครั้ง · ลบถาวร) · หน้ารายชื่อนักศึกษามี “ออกรหัสชั่วคราวที่เลือก” เพิ่ม

## จัดกลุ่มนักศึกษา (สำหรับงานกลุ่ม)
หน้า **นักศึกษา** มีแท็บ **รายชื่อ / กลุ่ม** · 1 คนอยู่ได้ 1 กลุ่มต่อวิชา · กลุ่มมีลำดับ + ชื่อ (ไม่บังคับ) + ตัวแทน/ผู้ประสานงาน (ไม่บังคับ ★)
- **ทางลัดที่สุด:** แท็บ *รายชื่อ* → ติ๊กนักศึกษาหลายคน → **ใส่เข้ากลุ่ม…** → เลือกกลุ่มจาก dropdown หรือ “+ กลุ่มใหม่” (ระบบเติมลำดับให้) · ตัวกรอง “ยังไม่มีกลุ่ม” ช่วยหาคนที่ตกค้าง · คอลัมน์ “กลุ่ม” เรียงได้
- แท็บ *กลุ่ม*: แก้ชื่อกลุ่ม · ตั้งตัวแทน ☆→★ · นำสมาชิกออก ✕ · เพิ่มสมาชิกจาก dropdown ในการ์ดกลุ่ม · ลบกลุ่ม (สมาชิกกลับเป็นไม่มีกลุ่ม)
- **แบ่งกลุ่มอัตโนมัติ…** (กี่คนต่อกลุ่ม · เรียงตามรหัสหรือสุ่ม · เฉพาะคนที่ยังไม่มีกลุ่ม หรือทั้งห้อง) · **วางจาก Excel…** (รหัส · ลำดับกลุ่ม · ชื่อกลุ่ม)
- ลบกลุ่มที่มีงานส่งแล้วไม่ได้ (ย้ายสมาชิกได้ — ระวังว่างานที่ส่งไว้ติดอยู่กับกลุ่มนั้น)

## งานกลุ่ม
สั่งงานแล้วเลือก **งานกลุ่ม** → เลือกการจัดกลุ่ม:
- **ใช้กลุ่มที่จัดไว้** — นักศึกษาเห็นกลุ่มของตัวเองทันที (ต้องจัดกลุ่มก่อน) · คนที่ยังไม่มีกลุ่มส่งไม่ได้ (ขึ้นว่าให้แจ้งอาจารย์)
- **ให้นักศึกษาจัดกลุ่มเอง** — กำหนดจำนวนสมาชิกสูงสุด ตัวแทนสร้างกลุ่มและเลือกเพื่อน (เหมือนเดิม)
- **สมาชิกทุกคนในกลุ่มส่ง/แก้งานได้** (ทั้งสองแบบ) จนกว่างานปิดรับหรืออาจารย์ให้คะแนนแล้ว · เปลี่ยนรูปแบบกลุ่มไม่ได้เมื่อมีการส่งหรือมีกลุ่มแล้ว
- ตรวจงาน: ให้คะแนนทั้งกลุ่ม หรือแยกรายคนได้ที่หน้าตรวจงาน · หน้าตรวจเห็น **ประวัติการแก้ไข** (ใคร ทำอะไร เมื่อไร ตั้งแต่คนแรกที่ส่งถึงคนล่าสุดที่แก้) และข้อความที่นักศึกษา **แจ้งเรื่องสมาชิกที่ไม่ช่วยงาน** ใช้ประกอบการให้คะแนนรายคน
- ระบบ **ไม่มีปุ่มให้ตัวแทนเอาเพื่อนออกจากกลุ่ม** — ถ้ามีคนไม่ช่วยงาน นักศึกษากด “แจ้งอาจารย์” แล้วอาจารย์ปรับคะแนนรายคนเอง
- เพื่อนในกลุ่มแก้ข้อความ/ลิงก์พร้อมกัน: ระบบไม่ทับเงียบๆ — คนที่บันทึกทีหลังเห็นข้อความของเพื่อนและเลือก “ใช้ของเพื่อน / เก็บของฉัน” (ไฟล์เป็นแบบเพิ่ม/ลบรายไฟล์ ไม่ชนกัน)

## กล่องข้อความจากนักศึกษา
นักศึกษากด **แจ้งอาจารย์** ที่หน้างานของตัวเอง (เลือกชื่อเพื่อนในกลุ่มที่เกี่ยวข้องได้ ไม่บังคับ · ไม่เกิน 500 ตัวอักษร · วันละไม่เกิน 10 ข้อความ) → อาจารย์เห็นป้าย **ข้อความใหม่** ที่การ์ดรายวิชา และเข้าหน้า **กล่องข้อความ** (ในหน้ารายวิชา) เพื่อค้นหา/เรียง/กรอง ทำเครื่องหมาย อ่านแล้ว · จัดการแล้ว · ลบที่เลือก · เพื่อนที่ถูกกล่าวถึงมองไม่เห็นข้อความ · ระบบไม่มีการตอบกลับ ให้ติดต่อนักศึกษานอกระบบแล้วกด “จัดการแล้ว” (นักศึกษาเห็นสถานะข้อความของตัวเอง)

## ใบลานักศึกษา
- **ผู้ดูแล (ตั้งครั้งเดียว):** ตั้งค่าระบบ → การ์ด **แบบฟอร์มใบลา** อัปโหลดไฟล์แบบฟอร์มการลา (นักศึกษากดดาวน์โหลดได้ที่หน้าส่งใบลา) · หมวด **ใบลา** เขียน **คำชี้แจงการลา** (แสดงให้นักศึกษาอ่านก่อนส่ง) และกำหนดว่าส่งย้อนหลัง/ล่วงหน้าได้กี่วัน (เริ่มต้น 14 / 30)
- **นักศึกษา:** หน้านักศึกษา → **ส่งใบลา** → เลือกอาจารย์ → วิชา → ชื่อ + PIN → ชนิดการลา (ป่วย/กิจ) · วันที่ · เวลาเรียน (ทั้งวัน/ระบุช่วง) · แนบ **ฟอร์มลาที่กรอกแล้ว (บังคับ)** + **หลักฐานเพิ่ม เช่น ใบรับรองแพทย์ (ไม่บังคับ)** · คำชี้แจงเพิ่มเติม · ยกเลิกได้ตราบที่ยังรออนุมัติ
- **อาจารย์:** หน้ารายวิชา → การ์ด **ใบลานักศึกษา** (มีป้ายจำนวนที่รออนุมัติ — ต้องมีสิทธิ์ระบบเช็คชื่อ) · ดู/ดาวน์โหลดไฟล์แนบ · **อนุมัติ / ไม่อนุมัติ** (ติ๊กหลายใบพร้อมกันได้ · หมายเหตุถึงนักศึกษาไม่บังคับ · เปลี่ยนคำตัดสินภายหลังได้) · **บันทึกการลาแทนนักศึกษา** (ใบกระดาษ) · ลบใบลา (ไฟล์แนบถูกลบด้วย)
- **ที่บันทึก:** ใบลาที่อนุมัติ → คาบที่ **ไม่มีบันทึกเช็คชื่อ** และตรงวันลา แสดงเป็น **“ล”** ในรายงานเช็คชื่อ/หน้าเช็คชื่อสด · แท็บ **สรุปการลา** (ลาป่วย/ลากิจ กี่ครั้ง กี่วัน + ส่งออก CSV) · หน้า **สรุปคะแนน** มีคอลัมน์ “ลา ป่วย/กิจ (วัน)” — **แสดงอย่างเดียว ไม่เปลี่ยนคะแนนเช็คชื่อ คะแนนรวม หรือเกรด** (ลา = ขาด ในการคิดคะแนนเหมือนเดิม ให้อาจารย์พิจารณาเองท้ายเทอม)
- **เตือนขาดเรียน:** ขาดเกิน N ครั้ง (ไม่นับคาบที่ลาตามใบลาที่อนุมัติ · ผู้ดูแลตั้ง N ที่ ตั้งค่าระบบ → เช็คชื่อ · เริ่มต้น **2** = ตั้งแต่ครั้งที่ 3) → นักศึกษาเห็นแบนเนอร์เตือนในหน้า “งานของฉัน” / “ส่งใบลา” พร้อมสรุปการเข้าเรียนรายวิชา · อาจารย์เห็น ⚠ ที่ชื่อในรายงานเช็คชื่อ และกรอง “ขาดเกินเกณฑ์” ในแท็บสรุปการลา
- **ความเป็นส่วนตัว:** ไฟล์ใบลา (ใบรับรองแพทย์เป็นข้อมูลสุขภาพ) เก็บใน Drive โฟลเดอร์ `HBT_Leave` ไม่แชร์ลิงก์ · เห็นเฉพาะอาจารย์เจ้าของวิชา/admin และบันทึกใน AuditLog ทุกครั้งที่เปิด · ลบเมื่อยกเลิกใบ/ลบนักศึกษา/ลบวิชา · สำรองสิ้นภาคเรียนไม่รวมไฟล์ใบลา (ส่งออก CSV สรุปการลาเก็บไว้เองได้)

## PIN นักศึกษา
- นักศึกษา **ตั้ง PIN 4 หลักเอง ตอนเข้าระบบครั้งแรกของภาคเรียน** (ไม่ต้องรอรหัสจากอาจารย์) ใช้ข้ามวิชาในภาคเรียนเดียวกัน · ภาคเรียนใหม่ตั้งใหม่ · อาจารย์ดู PIN จริงไม่ได้
- ลืม PIN / มีคนตั้งตัดหน้า: อาจารย์กด **ออกรหัสชั่วคราว** รายคนที่หน้ารายชื่อ (ใช้ครั้งเดียว อายุ 7 วัน) → นักศึกษาตั้งใหม่ที่หน้า PIN · ปุ่ม “ออกรหัสให้คนที่ยังไม่ตั้ง PIN” ใช้เมื่ออยากแจกรหัสให้ทั้งห้องเท่านั้น (ไม่จำเป็น)
- เช็คชื่อไม่ต้องใช้ PIN ได้: **ตั้งค่าระบบ → เช็คชื่อ → ติ๊กออกที่ "เช็คชื่อต้องใช้ PIN…" → บันทึก** (ผู้ดูแลเท่านั้น)
  ปิดแล้วเช็คชื่อยังตรวจ QR + GPS + 1 เครื่อง : 1 คน ต่อคาบ แต่ไม่กันเพื่อนเช็คแทนจากอีกเครื่อง ส่วนส่งงาน/สอบยังใช้ PIN เหมือนเดิม

## ลบรายวิชา
หน้าวิชา → ล่างสุด **ลบรายวิชานี้…** → พิมพ์รหัสวิชา-กลุ่มยืนยัน — ลบ **ถาวร** (รายชื่อ เช็คชื่อ คะแนน งานและไฟล์ ข้อสอบ ผลสอบ) กู้คืนไม่ได้ ควรสำรองข้อมูลวิชาก่อน · ถ้าค้างกลางทาง เปิดหน้ารายวิชาแล้วเข้าวิชาไม่ได้ ให้ผู้ดูแลลบต่อที่หน้า *ลบข้อมูลสิ้นภาคเรียน*

## สิ้นภาคเรียน
1. **สำรองข้อมูลวิชา** ดาวน์โหลด Zip ให้ครบจนสถานะเป็น "สำรองครบ"
2. ผู้ดูแล: **ลบข้อมูลสิ้นภาคเรียน** → เลือกวิชา → พิมพ์ข้อความยืนยัน — **ลบถาวร ไม่มีถังขยะ**

## ห้ามทำ
- ห้ามเปลี่ยน/ลบ `SEC_PIN` · ห้ามเปลี่ยน `SEC_TOKEN` โดยไม่จำเป็น · ห้ามแปะค่าเหล่านี้ในแชทหรือขึ้น Git
- ห้ามแก้ข้อมูลตรงๆ ในชีต · ห้ามลบ/ย้ายโฟลเดอร์ `HBT_Files/` ใน Drive
- ห้ามแก้โค้ดในตัวแก้ไข Apps Script (แก้ที่ repo แล้ว `clasp push`)

## อัปเดตระบบ (ผู้ดูแลเทคนิค)
- **แก้หน้าเว็บ (`web/`)**: `node tests/run_all.js` ผ่าน → `git commit` + `git push` → เว็บอัปเดตเองใน ~1 นาที
- **แก้ `gas/` หรือ `exam/`**: รันในโฟลเดอร์นั้นเท่านั้น
  ```
  clasp.cmd push
  clasp.cmd update-deployment <deploymentId เดิม> --description "ข้อความ"
  ```
  ใช้ deploymentId เดิมเพื่อให้ URL ไม่เปลี่ยน (ดูด้วย `clasp.cmd list-deployments`)
- ถ้า PowerShell ฟ้อง "running scripts is disabled" ให้ใช้ `clasp.cmd` แทน `clasp`

ข้อจำกัด: ชุดทดสอบรันกับตัวจำลอง ยังไม่เคยวัดโหลดจริงพร้อมกัน 30–100 คน ทดสอบกับกลุ่มเล็กก่อนใช้จริง

## ความเร็วและขีดจำกัด (ผู้ดูแลเทคนิค)
- ระบบอ่านชีตแบบรวดเดียว (ไม่อ่านทีละแถว) และแคชข้อมูลที่ไม่ค่อยเปลี่ยน (วิชา ภาคเรียน ผู้ใช้ รายชื่อ) ข้าม execution — เปลี่ยนข้อมูลแล้วเห็นทันที (แคชล้างเองเมื่อมีการเขียน, อายุสูงสุด 10 นาที)
- `node tests/run_all.js` มีชุด `core_perf_test.js` นับจำนวนคำสั่ง Sheets ต่อคำขอ: ห้อง 100 คนต้องไม่เกินเพดาน และต้องไม่โตตามจำนวนนักศึกษา ถ้าล้ม = มีโค้ดอ่านทีละแถวกลับเข้ามา
- เช็คชื่อพร้อมกันทั้งห้อง: การเขียนต้องเรียงทีละคนใน lock ตัวเดียว (ประมาณ 1–2 วินาที/คน บน Google จริง) — นักศึกษาที่รอคิวจะลองใหม่เอง (สูงสุด 8 ครั้ง) · ยังไม่เคยวัดเวลาจริงบน Apps Script ควรทดสอบกับกลุ่มเล็ก (20–30 คน) ก่อน
