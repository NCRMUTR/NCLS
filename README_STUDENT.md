# README ฝั่งนักศึกษา

เว็บ: https://ncrmutr.github.io/NCLS/ → กด **นักศึกษา** (หรือเปิด `…/NCLS/s/home.html`)
ไม่ต้องล็อกอิน ใช้ชื่อ/รหัสนักศึกษา + PIN 4 หลัก

## 1. ตั้ง PIN ครั้งแรก
1. ขอ **รหัสชั่วคราว** 4 หลักจากอาจารย์ (ใช้ได้ครั้งเดียว อายุ 7 วัน)
2. เปิดหน้า **ตั้ง / เปลี่ยน PIN** ใส่รหัสชั่วคราว แล้วตั้ง PIN ใหม่ 4 หลัก
3. จำ PIN ไว้ ใช้ได้ทุกวิชา อย่าบอกคนอื่น
4. ลืม PIN → ขอรหัสชั่วคราวจากอาจารย์ใหม่ · ใส่ PIN ผิดหลายครั้งจะถูกล็อกชั่วคราว รอสักครู่แล้วลองใหม่

## 2. เช็คชื่อ
1. สแกน **QR** ที่หน้าจออาจารย์ (หรือเปิดลิงก์ที่อาจารย์ส่งให้)
2. เลือกชื่อตัวเอง และอนุญาตให้เว็บใช้ **ตำแหน่ง (GPS)** ต้องอยู่ในห้อง/รัศมีที่อาจารย์กำหนด
3. กดเช็คชื่อ จะขึ้น ปกติ / สาย ตามเวลา
- 1 เครื่องเช็คชื่อให้ได้คนเดียวต่อคาบ ถ้าเครื่องถูกใช้แล้ว กด **ขออนุมัติ** ให้อาจารย์อนุมัติ
- บางวิชาอาจารย์อาจเปิดให้ใส่ PIN เมื่อใช้เครื่องใหม่ ให้ใส่ PIN ของคุณเมื่อระบบถาม
- ใช้ LINE ในแอปแล้ว GPS ไม่ขึ้น → เปิดลิงก์ด้วย Chrome/Safari

## 3. ส่งงาน
1. หน้านักศึกษา → **ส่งงาน** ใส่ **รหัสงาน** (`XXX-XXX`) หรือกดลิงก์ที่อาจารย์แจก หรือเปิดจาก **งานของฉัน**
2. เลือกชื่อ + ใส่ PIN
3. แนบไฟล์ (pdf, jpg, png, docx, xlsx, pptx ตามที่อาจารย์ตั้ง) หรือแปะลิงก์ แล้วส่ง
4. แก้ไฟล์ได้จนกว่างานจะปิดรับ หรืออาจารย์ให้คะแนนแล้ว
5. งานกลุ่ม: ตัวแทนสร้างกลุ่มและเลือกสมาชิก ส่งได้เฉพาะตัวแทน
6. ดูสถานะ/คะแนนที่หน้า **งานของฉัน / สถานะการส่ง**

## 4. สอบออนไลน์
1. เปิดลิงก์รอบสอบที่อาจารย์แจก
2. เลือกชื่อ + ใส่ PIN → อ่านเงื่อนไข → เริ่มทำ
3. อย่าออกนอกหน้าจอหรือสลับแท็บ ระบบนับจำนวนครั้ง
4. เน็ตหลุดไม่ต้องตกใจ กลับมาเปิดลิงก์เดิมแล้วกด **ทำต่อจากเดิม** คำตอบที่ค้างจะถูกส่งต่อเอง
5. หมดเวลาหรือเลยกำหนด ระบบส่งให้อัตโนมัติ

## ปัญหาที่พบบ่อย
| อาการ | ทำอย่างไร |
|---|---|
| ไม่มีชื่อในรายการ | แจ้งอาจารย์ให้เพิ่มรหัสนักศึกษาในวิชา |
| ใส่ PIN ไม่ผ่าน / ถูกล็อก | รอสักครู่ หรือขอรหัสชั่วคราวใหม่จากอาจารย์ |
| GPS ไม่ทำงาน | อนุญาตตำแหน่งในเบราว์เซอร์ และเปิดด้วย Chrome/Safari |
| อัปโหลดไฟล์ไม่ได้ | ตรวจนามสกุลและขนาดไฟล์ตามที่ระบบบอก ไฟล์ใหญ่ให้แปะลิงก์แทน |
