# README ฝั่งนักศึกษา

เว็บ: https://ncrmutr.github.io/NCLS/ → กด **นักศึกษา** (หรือเปิด `…/NCLS/s/home.html`)
ไม่ต้องล็อกอิน ใช้ชื่อ/รหัสนักศึกษา + PIN 4 หลัก

## 1. ตั้ง PIN ครั้งแรก (ทุกภาคเรียน)
1. เข้าระบบครั้งแรกของภาคเรียน (เช็คชื่อ / ส่งงาน / สอบ) ถ้ายังไม่มี PIN ระบบจะให้ **ตั้ง PIN เองได้เลย** — ใส่เลข 4 หลัก 2 ครั้ง ไม่ต้องรอรหัสจากอาจารย์
2. จำ PIN ไว้ ใช้ได้ทุกวิชาในภาคเรียนนั้น อย่าบอกคนอื่น · ภาคเรียนใหม่ต้องตั้งใหม่
3. ลืม PIN → ขอ **รหัสชั่วคราว** (ใช้ครั้งเดียว อายุ 7 วัน) จากอาจารย์ แล้วตั้งใหม่ที่หน้า **ตั้ง / เปลี่ยน PIN** · ใส่ PIN ผิดหลายครั้งจะถูกล็อกชั่วคราว รอสักครู่แล้วลองใหม่

## 2. เช็คชื่อ
1. สแกน **QR** ที่หน้าจออาจารย์ (หรือเปิดลิงก์ที่อาจารย์ส่งให้)
2. **กรอกรหัสนักศึกษา** ของตัวเอง (ระบบเทียบกับรายชื่อวิชา ถ้าไม่ตรงจะแจ้งให้ตรวจสอบแล้วกรอกใหม่) และอนุญาตให้เว็บใช้ **ตำแหน่ง (GPS)** ต้องอยู่ในห้อง/รัศมีที่อาจารย์กำหนด
3. กดเช็คชื่อ หน้าสรุปจะแสดง **ชื่อและรหัสของคุณ** พร้อมสถานะ ปกติ / สาย ตามเวลา
- 1 เครื่องเช็คชื่อให้ได้คนเดียวต่อคาบ ถ้าเครื่องถูกใช้แล้ว กด **ขออนุมัติ** ให้อาจารย์อนุมัติ
- บางวิชาอาจารย์อาจเปิดให้ใส่ PIN เมื่อใช้เครื่องใหม่ ให้ใส่ PIN ของคุณเมื่อระบบถาม
- ใช้ LINE ในแอปแล้ว GPS ไม่ขึ้น → เปิดลิงก์ด้วย Chrome/Safari

## 3. ส่งงาน
1. หน้านักศึกษา → **ส่งงาน** ใส่ **รหัสงาน** (`XXX-XXX`) หรือกดลิงก์ที่อาจารย์แจก หรือเปิดจาก **งานของฉัน**
2. เลือกชื่อ + ใส่ PIN
3. แนบไฟล์ (pdf, jpg, png, docx, xlsx, pptx ตามที่อาจารย์ตั้ง) หรือแปะลิงก์ แล้วส่ง
4. แก้ไฟล์ได้จนกว่างานจะปิดรับ หรืออาจารย์ให้คะแนนแล้ว
5. **แจ้งอาจารย์:** ปุ่ม “แจ้งอาจารย์” ที่หน้างานและหน้างานของฉัน — ส่งข้อความถึงอาจารย์ได้ (เช่น เพื่อนไม่ช่วยงาน เลือกชื่อเพื่อนได้) วันละไม่เกิน 10 ข้อความ เพื่อนไม่เห็นข้อความของคุณ ดูสถานะที่ส่งไว้ได้ในหน้าต่างเดียวกัน
5.1 งานกลุ่ม: หน้าส่งงานมี **ประวัติการแก้ไข** (ใครส่งก่อน ใครแก้ล่าสุด) · ถ้าเพื่อนเพิ่งแก้ข้อความที่คุณกำลังพิมพ์ ระบบจะไม่ทับ ให้เลือก “ใช้ของเพื่อน” หรือ “เก็บของฉัน” · งานที่อาจารย์จัดกลุ่มให้มี dropdown กลุ่ม (เห็นลำดับ+ชื่อทุกกลุ่ม แต่ดูสมาชิกและงานได้เฉพาะกลุ่มของคุณ)
5.2 งานกลุ่ม: **สมาชิกทุกคนในกลุ่มดูงานที่ส่งและแก้ไขได้** (จนกว่างานปิดรับหรืออาจารย์ตรวจแล้ว) · กลุ่มมี 2 แบบตามที่อาจารย์เลือก: (ก) **อาจารย์จัดกลุ่มให้** — เปิดงานแล้วเห็นกลุ่มและรายชื่อของตัวเองทันที ถ้าไม่เห็นกลุ่ม = อาจารย์ยังไม่ได้จัดคุณเข้ากลุ่ม ให้แจ้งอาจารย์ (ข) **จัดกลุ่มเอง** — ตัวแทนสร้างกลุ่มและเลือกสมาชิก (แก้รายชื่อสมาชิกได้เฉพาะตัวแทน)
6. ดูสถานะ/คะแนนที่หน้า **งานของฉัน / สถานะการส่ง**

## 4. สอบออนไลน์
1. เปิดลิงก์รอบสอบที่อาจารย์แจก
2. เลือกชื่อ + ใส่ PIN → อ่านเงื่อนไข → เริ่มทำ
3. อย่าออกนอกหน้าจอหรือสลับแท็บ ระบบนับจำนวนครั้ง
4. เน็ตหลุดไม่ต้องตกใจ กลับมาเปิดลิงก์เดิมแล้วกด **ทำต่อจากเดิม** คำตอบที่ค้างจะถูกส่งต่อเอง
5. หมดเวลาหรือเลยกำหนด ระบบส่งให้อัตโนมัติ

## ปัญหาที่พบบ่อย
| อาการ | ทำอย่างไร |
|---|---|
| ไม่มีชื่อในรายการ | แจ้งอาจารย์ให้เพิ่มรหัสนักศึกษาในวิชา |
| ใส่ PIN ไม่ผ่าน / ถูกล็อก | รอสักครู่ หรือขอรหัสชั่วคราวใหม่จากอาจารย์ |
| GPS ไม่ทำงาน | อนุญาตตำแหน่งในเบราว์เซอร์ และเปิดด้วย Chrome/Safari |
| อัปโหลดไฟล์ไม่ได้ | ตรวจนามสกุลและขนาดไฟล์ตามที่ระบบบอก ไฟล์ใหญ่ให้แปะลิงก์แทน |
